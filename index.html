📐 Метрологическое обоснование расчёта Пересчёт выполняется по уравнению состояния идеального газа (Менделеева—Клапейрона) при заданных абсолютном давлении и температуре.

C(мг/м³) = C(ppm) × M × P / (R × T)

Где:
• M — молярная масса газа (г/моль)
• P — абсолютное давление (кПа)
• T — абсолютная температура (К) = t °C + 273,15
• R = 8,314462 кПа·л/(моль·К) — универсальная газовая постоянная

Обратный пересчёт: C(ppm) = C(мг/м³) × R × T / (M × P)

Для метана (CH₄) дополнительно используется значение НКПР = 5,0 %VOL,
откуда: 1 %LEL = 0,05 %VOL = 500 ppm.

Метрологическое примечание. Пересчёт между ppm и мг/м³ выполняется по уравнению состояния идеального газа и зависит от температуры и абсолютного давления. При использовании значений из справочных таблиц необходимо учитывать условия, для которых они были рассчитаны.

О точности вычислений. Результаты отображаются с учётом округления. Внутренние вычисления выполняются с полной точностью JavaScript (IEEE 754, 64-битное число двойной точности).

Ограничение модели. Расчёт использует модель идеального газа без поправки на коэффициент сжимаемости Z; допущение корректно вблизи атмосферного давления и для типичных концентраций переносных газоанализаторов; при значительном отклонении давления от атмосферного (например, подача из баллона под давлением) поправка не учитывается.
